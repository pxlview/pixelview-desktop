# Pixelview Desktop 0.0.12

Twelfth release, and the first for Windows (x64, Windows 10 22H2 or 11).

- Pixelview Desktop for Windows: pair with a node, capture (including DeckLink and the built-in test patterns) and send to Pixelview, with hardware HEVC and H.264 on NVIDIA (NVENC), AMD (AMF) and Intel (Quick Sync), and x264 as the fallback. The installer is per user, needs no administrator rights and registers pixelview:// links. Receiving is not available on Windows yet.
- Automatic updates on Windows: Pixelview Desktop checks for updates once a day and offers new versions when they are available, as on the Mac; Help > Check for Updates checks at once. Updates are signed and verified before they are installed, and the app restarts after the update.
- Lower latency with NVIDIA encoders: NVENC now hands over each frame as soon as it is encoded instead of buffering three frames, and constant-bitrate streams use a one-frame buffer.
- Every encoder now defaults to a two-second keyframe interval (previously one second for H.264 and x264). Existing encoder settings are kept as they are.
- H.264 and HEVC streams now repeat their parameter sets on every keyframe, so viewers who join a stream late always get a picture. This fixes a black picture in browsers for NVIDIA-encoded streams.
- AMD graphics: HEVC Main and, where the GPU supports it, Main10 are now available.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot `32.2.1-66-g6b3e55072` (commit `6b3e550729f125b6c5b3767df88c08f5aef9d264`). It is not an official OBS Project release.
