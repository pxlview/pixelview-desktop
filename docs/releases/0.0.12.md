# Pixelview Desktop 0.0.12

Twelfth release, and the first for Windows (x64, Windows 10 22H2 or 11).

- First Windows version: pair with a node, capture (including DeckLink and the built-in test patterns) and send to Pixelview, with automatic updates as on the Mac. Receiving is not available on Windows yet.
- 4:4:4 10-bit (on the Mac): send, receive and play out 4:4:4 10-bit from RGB SDI sources with no chroma subsampling.
- HDR sending: the node's colour profile in Pixelview admin now decides whether Pixelview Desktop sends SDR or HDR (PQ or HLG, including P3-D65).
- Connection stats: while streaming, Pixelview Desktop reports its connection quality and how busy the computer is, and Pixelview admin shows it for each Desktop.
- Fixed a crash at launch on computers with other OBS plugins installed: Pixelview Desktop now loads only its own plugins.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot `32.2.1-66-g6b3e55072` (commit `6b3e550729f125b6c5b3767df88c08f5aef9d264`). It is not an official OBS Project release.
