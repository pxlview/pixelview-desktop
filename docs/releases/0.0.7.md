# Pixelview Desktop 0.0.7

Seventh Apple Silicon release.

- Receiving is now in sync and much faster: audio no longer lags behind the picture, and HEVC streams arrive about 0.6 seconds sooner.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot `32.2.1-66-g6b3e55072` (commit `6b3e550729f125b6c5b3767df88c08f5aef9d264`). It is not an official OBS Project release.

Corresponding source: https://github.com/pxlview/pixelview-desktop/tree/v0.0.7
