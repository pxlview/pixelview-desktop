# Pixelview Desktop 0.0.1

First Apple Silicon release of Pixelview Desktop.

- Focused Pixelview capture and streaming interface.
- Blackmagic DeckLink capture workflow with native device settings.
- Pixelview pairing, authenticated control, and lease-gated WHIP streaming.
- VideoToolbox hardware encoding and native audio monitoring controls.
- Signed Sparkle updates from Pixelview-owned infrastructure.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot `32.2.1-66-g6b3e55072` (commit `6b3e550729f125b6c5b3767df88c08f5aef9d264`). It is not an official OBS Project release.

Corresponding source: https://github.com/pxlview/pixelview-desktop/tree/v0.0.1
