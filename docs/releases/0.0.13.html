Pixelview Desktop 0.0.13

Thirteenth release, for the Mac.

  • Fixed Pixelview Desktop freezing at startup on some Macs. The video components used for receiving now load only when you first start receiving, and if they ever fail to load, only receiving is affected: the app still opens and streams.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.

Corresponding source: https://github.com/pxlview/pixelview-desktop/tree/v0.0.13
