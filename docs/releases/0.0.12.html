Pixelview Desktop 0.0.12

Twelfth release, and the first for Windows (x64, Windows 10 22H2 or 11).

  • Pixelview Desktop for Windows: pair with a node, capture (including DeckLink and the built-in test patterns) and send to Pixelview, with hardware HEVC and H.264 on NVIDIA (NVENC), AMD (AMF) and Intel (Quick Sync), and x264 as the fallback. The installer is per user, needs no administrator rights and registers pixelview:// links. Receiving is not available on Windows yet.
  • Automatic updates on Windows: Pixelview Desktop checks for updates once a day and offers new versions when they are available, as on the Mac; Help > Check for Updates checks at once. Updates are signed and verified before they are installed, and the app restarts after the update.
  • Lower latency with NVIDIA encoders: NVENC now hands over each frame as soon as it is encoded instead of buffering three frames, and constant-bitrate streams use a one-frame buffer.
  • Every encoder now defaults to a two-second keyframe interval (previously one second for H.264 and x264). Existing encoder settings are kept as they are.
  • H.264 and HEVC streams now repeat their parameter sets on every keyframe, so viewers who join a stream late always get a picture. This fixes a black picture in browsers for NVIDIA-encoded streams.
  • AMD graphics: HEVC Main and, where the GPU supports it, Main10 are now available.
  • On the Mac: HDR sending. The node's input colour profile in Pixelview admin now decides what Pixelview Desktop sends: Rec.709 SDR, Rec.2100 PQ or HLG, or P3-D65 PQ. For PQ the node's maximum luminance becomes the HDR peak in the stream's metadata. For the new "P3-D65 PQ/ST2084 — sending with Pixelview Desktop" profile, the DeckLink capture is converted from P3 to BT.2020 on the Mac, so the stream needs no conversion on the server. The sidebar shows the profile, and a change made while streaming applies after the stream. HDR needs a 10-bit HEVC profile, so 8-bit Main and H.264 are replaced by Main10.
  • On the Mac: HEVC Main 4:4:4 10 for RGB sources. A 10-bit RGB SDI signal can be captured, sent and received without chroma subsampling, and played out again as 10-bit 4:4:4 RGB on a DeckLink output. The profile is offered only where the Mac's hardware encoder supports it; browsers get a transcode.
  • Connection quality in Pixelview admin: while streaming, Pixelview Desktop reports its bitrate, the round trip, loss and jitter the media server measures, and how busy the computer is, so the admin can show signal bars for each Desktop and tell an overloaded computer from a bad network.
  • Pixelview Desktop now loads only the plugins that ship with it, never OBS plugins installed elsewhere on the computer. This fixes a crash at launch on computers with other OBS plugins installed.
  • On the Mac: receiving picks the best stream format more reliably. A rare failed decoder check at startup could make the server send a transcoded stream instead of the original until the app was restarted.
  • On the Mac: when HDR cannot change because a DeckLink output is running, the message now says to stop the output in DeckLink output settings first.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
