Pixelview Desktop 0.0.9

Ninth Apple Silicon release.

  • 10-bit 4:2:2 receive: an HEVC Main 4:2:2 10 stream is now decoded in hardware and keeps its full 4:2:2 chroma all the way to the DeckLink output, instead of being reduced to 4:2:0.
  • The DeckLink output always sends 10-bit 4:2:2 Y'CbCr on SDI, in SDR as well as HDR, and the DeckLink capture defaults to 10-bit, so the picture stays 10-bit from SDI in to SDI out whichever profile the stream uses.
  • Improved levels handling: limited-range video is no longer clipped to 64-940, so sub-black and super-white pass through, and 8-bit streams are widened to 10 bits without a level shift.
  • New Output range setting (Limited or Full) on the DeckLink output. Set the sender's input range to match the grading system and the receiver's output range to match the monitor.
  • Sharper colour detail: chroma is no longer softened an extra time when sending or receiving.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
