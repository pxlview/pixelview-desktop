Pixelview Desktop 0.0.4

Fourth Apple Silicon release.

  • Pairing as a sender works again: the app now ships the TLS component its pairing request needs. Without it every pairing attempt failed before reaching Pixelview.
  • Streaming to Pixelview works again: the app no longer rejects the stream address Pixelview returns after accepting the WHIP offer.
  • A pairing that fails now says why on screen (Pixelview unreachable, invalid or expired code, too many attempts), and pairing, Keychain and connection outcomes are written to the application log. Pairing codes and device tokens are never logged.
  • The short 6-character pairing codes from Pixelview admin are accepted; surrounding spaces are ignored.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
