Pixelview Desktop 0.0.8

Eighth Apple Silicon release.

  • Receiving now recovers on its own: if the stream stalls or the sender drops out, the Mac reconnects automatically within seconds instead of stopping.
  • The DeckLink output keeps playing while the stream reconnects, and the app no longer freezes after a stream interruption.
  • Short audio dropouts under heavy load are gone.
  • When sending, the HEVC profile list marks Main10 as recommended and explains that Main 4:2:2 10 is transcoded by the server for most viewers.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
