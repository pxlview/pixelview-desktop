Pixelview Desktop 0.0.11

Eleventh Apple Silicon release.

  • Test patterns: you can test a stream without a capture card. The Capture list now also offers built-in test patterns (SMPTE bars, EBU and 100 % bars, gray ramps and steps, RGB ramps, a crosshatch, a zone plate and black) with a once-a-second sync beep and a burned-in clock and frame counter, so audio and video sync can be checked at the receiving end.
  • Encoder profiles that a node's region does not support are no longer offered. For nodes in Sydney and Tokyo this hides Main 4:2:2 10; if it was selected, Pixelview Desktop switches to Main10 (after the current stream, if one is running).

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
