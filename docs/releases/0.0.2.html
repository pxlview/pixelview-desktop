Pixelview Desktop 0.0.2

Second Apple Silicon release.

  • Receiving reports clearly why it stopped: removed by the host, or the session was deleted or expired.
  • A receiver removed by the host is not offered a rejoin of that session.
  • The installer window now shows only the app and the Applications shortcut; license files are in a Licenses folder.
  • Website downloads use a stable latest link that always serves the newest release.
  • The DeckLink receive output no longer stops on short gaps in the incoming stream and logs the reason when it does stop.
  • The Desktop control connection uses the platform's standard WebSocket protocol; a running stream survives control reconnects.
  • Receiving refuses HEVC 4:2:2 10-bit streams with guidance to use HEVC Main or Main10.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
