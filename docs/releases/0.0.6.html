Pixelview Desktop 0.0.6

Sixth Apple Silicon release.

  • Stopping a stream from Pixelview admin now completes right away instead of timing out, and the Mac stays online when a stream is stopped (from admin or on the Mac).

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
