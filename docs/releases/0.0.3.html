Pixelview Desktop 0.0.3

Third Apple Silicon release.

  • Receiving no longer inherits the Sending frame rate: the DeckLink output mode you choose sets the receive frame rate, so an unpaired receiver can play out 24p, 25p or any other supported mode.
  • A DeckLink output that does not start now shows the reason on screen (nothing received yet, device or mode unavailable, card in use, frame-rate mismatch) instead of only writing it to the log.
  • The window title shows the app version, and a new About Pixelview Desktop item shows version and build details.

Pixelview Desktop is a modified distribution based on OBS Studio development snapshot 32.2.1-66-g6b3e55072 (commit 6b3e550729f125b6c5b3767df88c08f5aef9d264). It is not an official OBS Project release.
